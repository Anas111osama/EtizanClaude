# Etizan explainer video

The first video made with this pipeline: parents' guide to the kids track (`D:\Anas\Nasieg\ETIZAN\App Video`, Oct 2026). The user loved the result: keep this style unless they ask otherwise.

Reusable code is in `pipeline/` next to this file. Copy it into `<video folder>/build/`, then `npm i puppeteer-core gsap`.

## What's in `pipeline/`
- Root: the app explainer engine (`video.html` + `script.js`, `seed.js`, `shots.js`/`shoot.js`, `transcribe.py`/`align.py`, `gaps*.py`/`clipcheck.py`/`cut.py`, `events.js`/`mix.py`, `frames.js`/`render.js`, `contact.py`, `explore.js` = list/click buttons on an app page to find selectors).
- `sfx.py` (whoosh/swish/pop/slap/rise), `sfx2.py` (impact/lowhit/whoosh_big/riser/reverse/glitch/drone/stinger/boom), `sfx3.py` (flip/marker/print): they write `sfx/<name>.wav`. **Pre-rendered copies of all 17 are already in `pipeline/sfx/`**, so just copy that folder instead of regenerating.
- `assets/`: `cairo.woff2`, `logo-full.png`, `logo-mark.png`, `booklet.png`, `fontawesome/`.
- `tips/` tips-series engine (+ `example_ep02/`) · `members/` org-members variant of the explainer (`video.html` with its own intro/outro, `mshoot.js` + `mshots.js`) · `shorts/` · `teaser/` · `booklet/` · `admin16x9/` (+ `mocks/` = `admin-test.html`, `mock-admin.js`, `mock-member.js`, which live in the app's `www/.design/`) · `sessions_ad/` (`sshoot.js` + `mock-sessions.js`).
- Scripts still point at the user's other project folders (`../../App Video/...`, `../../Adult_App/...`, `../../app/V2.2 - TESTING/www/`); those (app code, recorded VOs, screens, hooks, wind/bird/pencil audio, booklet page renders `hi/pNN.png`) are not in this repo — ask the user for them when a video needs them.

## Running in a Claude Code cloud session (Linux)
- Every Puppeteer script reads `process.env.CHROME` (falls back to the Windows Chrome path). On Linux: `export CHROME=<pipeline>/linux-chrome.sh` (runs `/opt/pw-browsers/chromium --no-sandbox`; root needs no-sandbox).
- `pip install numpy pillow faster-whisper pymupdf`; ffmpeg and Node are preinstalled. The whisper `small` model downloads from `huggingface.co`, which must be in the environment's allowed domains (Network access → Custom), then everything runs with `local_files_only=True`.
- `tips/video.html` loads `node_modules/gsap` relative to itself: symlink `tips/node_modules` → `../node_modules` (or `npm i` inside it).
- Session containers are ephemeral: packages and the model must be reinstalled per session (or via the environment's setup script).

## Voice: the user generates it (decided Oct 2026)
Claude does **not** generate the voice and does not try local/open TTS models (no open model matches Puck's Egyptian-Arabic quality, and the cloud box has no GPU). For every episode/video Claude hands the user, in chat:
1. The **voice style prompt** (English, like `tips/style_puck.txt`) for AI Studio's style box.
2. The **script**: one sentence per line, numbered, each starting with its `[tone; pronunciation hint]` tag; tashkeel/shadda where pronunciation matters (ابنِك، قايلّه); numbers as words; steps as «أول حاجة / تاني حاجة / تالت حاجة». No pause tags in the text (pauses are added at assembly from `gaps.txt`).
3. What to send back: **one file per line** named `line_001.wav`, `line_002.wav`… in script order (WAV or MP3, any sample rate; `vo.py` converts), uploaded to the branch under `epNN/voice/` or sent in chat. One file for the whole video is also accepted (then Claude splits it with whisper alignment). Bad lines are re-done one by one.

After the files arrive: run `vo.py` / `transcribe.py`, check per-line coverage and spoken tags, and report bad lines **by number** so the user regenerates only those. Tell the user checks are by transcript, not by ear.

The old direct path (only if the user asks for it again): `D:\Anas\Nasieg\ETIZAN\tools\tts.py` (not in this repo) calls Gemini TTS directly (`gemini-3.8-flash-tts`, REST `v1beta/interactions`, header `x-goog-api-key`, audio base64 in `steps[].content[]` type audio, 24 kHz mono WAV). Key is in `D:\Anas\Nasieg\ETIZAN\.env` (`GEMINI_API_KEY=`), never print or echo it. The API does NOT support `[square]` tags (they would be read aloud): the script strips them and turns them into that line's `style` on top of the general voice description; inline `<sigh>`/`<short pause>` are supported. Usage: `--text "[tags] نص" --out x.wav` for one line, or `--script lines.txt --style-file style.txt --outdir voice/ [--only 3,7]` for one WAV per line (regenerate single bad lines). Verify with faster-whisper after generating.

## Workflow
1. **Script first** (the user generates the voice, see «Voice» above). Egyptian colloquial, short lines, one idea per line, numbers written as words, English acronyms spelled in Arabic letters (إيه دي إتش دي). Give a voice-style prompt (English) + the numbered lines with tags, and ask for one file per line. **Do not put `[long pause]`/pause tags in the text: the TTS sometimes reads them aloud.** Separate scenes with blank lines only; emotion tags like `[warm]` at line start are OK. Then wait for the voice and the go-ahead.
2. **Screenshots**: `shots.js` lists shots `{name, url, full?, hour?, extraSeed?, act?, targets}`. `seed.js` fills localStorage with realistic demo data (guest mode, birthdate, name, streak, XP, schedule, rewards…) and marks every `tour_*_done` flag so spotlight tours don't cover screens. `shoot.js` fakes the clock (`hour/min`), shoots at 390×844 @3x, and saves highlight rects to `screens/rects.json` (+ make `rects.js`). Target syntax: `'$css'`, `'text'` (smallest element containing it), `'text@closest-sel'`, `'&css:n'` (union box of first n matches). Use viewport shots (not `full`) for pages with fixed bottom buttons. Review with `contact.py` sheets.
   Full-page shots hide fixed/sticky bottom bars (they'd land mid-page); non-full shots store viewport coordinates, so an `act` may scroll first. Watch for pop-ups that cover screens (notification prompt, widget onboarding `etizan_widget_onboarding_shown`, intent popup `userIntent`, daily reward needs `lastLoginDate` = yesterday) and either dismiss them or use them as shots. Check every feature the script claims actually exists in the UI before recording (video 2: the AI "رفيقك/الكوتش" personas exist in code but have no switch button).
3. **Timing** (run `python build/transcribe.py` from the video root folder, not from `build/`): `transcribe.py` (faster-whisper **small, CPU, int8, local_files_only**; the GPU path and large-v3-turbo download hung here) → `align.py` char-aligns the known script to whisper words, snaps line starts to real speech onsets, and writes `times.js` with per-word times. All 58 lines matched ≥0.72 in video 1.
4. **Spoken tags check**: run `gaps.py`/`gaps2.py` (speech blobs between lines) and `clipcheck.py` (re-transcribe suspect gaps in en+ar). Cut confirmed junk with `cut.py` (keep the original as `VOICE_OVER_original.wav`), re-transcribe, re-align. Everything downstream re-times automatically.
5. **Motion page** `video.html` + `script.js` (scenes → lines with `shot`, `focus`, optional `then: [[fraction, {shot?, focus}]]`, `chips`, `sfx`). Built only after Cairo loads (`BUILD()`), GSAP timeline, `window.seek(t)` deterministic. Elements: header badge + auto-fit title, phone mockup with screenshot that scrolls to the target, dimmed spotlight ring, **magnifier card** (enlarged copy of small targets over the phone; never camera-zoom the phone, it drops out of frame), floating skill chips, word-by-word captions synced to `times.js`. Intro/outro are kinetic typography with **each element keyed to its spoken word** (`W(line, wordIndex)`); the intro's big text must be the exact spoken words.
6. Check frames with `node frames.js t1 t2 …` → `tmp/f_t.jpg` and look at sheets before rendering.
7. **Audio**: `node events.js` (SFX cue list) → `python mix.py` (voice loudnorm, wind loop ducked under speech, birds/pencil slices, SFX thinned to ≥0.7 s apart, final −15 LUFS).
   In the 9:16 `video.html`, `then: [[f, …]]` takes a fraction of the line (<1) or a word index (≥1); `pipeline/video.html` and `pipeline/members/video.html` both support it (older copies on the user's disk may not: there a word index schedules the change far after the end). JS comments inside a one-line Python patch must be `/* */`, never `//`.
   `window.seek` must return nothing (`t => { tl.seek(t, false); }`): returning the timeline makes Puppeteer serialize it and hang.
   **Teaser variant** (10–15 s, `D:\Anas\Nasieg\ETIZAN\Teaser`): no new voice; quotes are cut from the two existing VOs (`clips.py` trims silence, verify each clip by re-transcribing for bleed from neighbour words), `plan.py` is the single timeline for picture + sound, glass panels with blur/mask reveals, `sfx2.py` makes impact/low hit/big whoosh/riser/reverse swell/glitch/muffled drone from noise + sub sweeps (no melody), mix at −14 LUFS.
   **Shorts library** (`D:\Anas\Nasieg\ETIZAN\Shorts`, 15 done Oct 2026): `build/shorts.py` = one spec per short (format A feature reveal / B UI glass showcase / C dark hook → BOOM → solution, hook = Puck clip `source/hooks/hookNN.wav`, VO segments cut by word index from both recordings, shot/focus/then/chips); `python make.py N` cuts + levels clips, writes `plan.js` + `mix_N.wav`; same `video.html` renders all formats; end card VO = full «نزّل اتزان النهارده… وابدأ…» line. Keep each short on the hook's topic (user rejected an off-topic one). Custom highlight areas can be added straight into `screens/rects.json`.
   **16:9 desktop variant** (org dashboard, `D:\Anas\Nasieg\ETIZAN\Admin_Video`): `ashoot.js` shoots `admin.html` at 1440×900@2x from `.design/admin-test.html` (localStorage `mock_role` admin|manager, `mock_type` school|speech|behavior, `mock_caseload`, `etz_admin_guide_seen`), swapping the org name per type by request interception; sheets opened by importing `/assets/js/admin/sheets.js`; target syntax adds `col:<header>:n` (table column) and `%sel|n` (nth element). `scenes.js` maps every line to win/split/phone/legend/intro/outro with a «متاح عند» scope badge; member-side phone shots come from the real home pages with `supabase-client.js` intercepted to `.design/mock-member.js` (`mshoot.js`). Set frames/render viewport to 1920×1080.
   **Paper/booklet style** (product promos, `D:\Anas\Nasieg\ETIZAN\Booklet_Video`): light notebook background (ruled sky lines + margin), real PDF pages rendered with PyMuPDF (`pymupdf`, dpi 200) as tilted paper cards, sticky notes, highlighter boxes in page fractions, marker strikes measured from the DOM, 3D book cover, printer, phone receiving the PDF; scenes are hand-written per line with word times `W(line, word)`; extra SFX `flip/marker/print` from `sfx3.py` (mixer must list them in `S`/`GAIN`/`PRI`).
8. **Render**: `node render.js a b parts/pN.mp4` in 4 parallel workers (~11 fps each, ~5 min for 5 min video), concat with `parts.txt`, mux `mix.wav` → `out/<name>.mp4` (`+faststart`). Verify by extracting frames and re-transcribing cut points from the final file. Send with SendUserFile.


## Tips series «اللي محدش بيقولهولك» (motion graphics, no app screens) — `D:\Anas\Nasieg\ETIZAN\Tips_Series`
10 non-medical parenting reels, 9:16, ~50–60 s, Puck voice generated by the user from Claude's script, captions ON (the user prefers them). Engine copy: `pipeline/tips/`, worked example: `pipeline/tips/example_ep02/`.
- Folder per episode: `epNN/script.txt` (one line per sentence, `[tags]` first), `epNN/gaps.txt` (`i seconds` pause after line i), `epNN/scenes.js`.
- Voice: give the user `style_puck.txt` + `epNN/script.txt`; they return `epNN/voice/line_NNN.wav|mp3` → `python build/vo.py epNN` (trims each line, joins with the gaps, whisper per line + char alignment → `epNN/times.js` with per-word times; prints coverage per line, ≥0.8 is fine).
- Scenes: `window.EPISODE = { n, next, endCard, seriesReveal?, build(A) }`; `A` gives `tl, fx, el, px, W(line, word), LN, scene(a,b), pop, chip, center, sticky, strike, bigText, ring, dyn, lerp, AR`. Key every element to its spoken word with `W(i,k)` (0-based line/word, words split on spaces of the script text). Shared engine (`build/video.html?ep=epNN`) draws background, series badge, chunked word-by-word captions (≤4 words, current word yellow) and the end card (logo + series badge + «الحلقة الجاية»). `?nocap=1` / `NOCAP=1` renders without captions.
- Structure that works: hook (relatable scene) → «مش… المشكلة في…» reveal → simple non-medical explanation (metaphor) → «فالحل مش… الحل…» → 3 step cards with dots indicator → one-line takeaway → share/save CTA. Sell (app or «دليل اتزان») in only 4 of 10 episodes (2, 3, 7, 8).
- Check: `EP=epNN node frames.js t…` + `python sheet.py out.jpg frames…`, then `EP=epNN node events.js` → `python mix.py epNN` (−14 LUFS, fixed gain + limiter) → 3 parallel `EP=epNN node render.js a b parts/x.mp4` (4 workers ran out of memory once) → concat + mux → `epNN/out/`.
- GSAP gotchas: `fromTo` renders its start state immediately — use `immediateRender:false` for flashes/shakes/drops that start later, or the whole video gets washed. Counters/timers go in `dyn(t => …)` (called every seek). Clocks/timers use Western digits (Cairo draws ٠ like a dot, ٢ like Γ, ٦ like 1). Quote marks «» next to other punctuation break bidi in chips — rephrase without them. Don't repeat the caption as big on-screen text.

## Gemini TTS lessons (free tier: 10 requests/day per model, 3/min)
- `gemini-3.8-flash-lite-tts` has its own 10/day and a very close Puck voice (a bit calmer): use it for one fix line or a whole episode, not mixed inside one sentence.
- Write steps as «أول حاجة / تاني حاجة / تالت حاجة» — «تانياً» came out «تنيّا» and «تالتاً» «تلتا».
- Shadda/kasra matter: «قايلّه» needed a shadda + hint in the tag; feminine address needs kasra (ابنِك، فلوسِك) plus "the listener is a woman" in the style prompt.
- A pronunciation hint in the line's tag works: `[warm; pronounce X as 'taa-lit' with a long aa]`. Verify by whisper (e.g. «ثالث» = long aa, «ثلت/تلتن» = short) and compare word durations old vs new; tell the user it's verified by transcript, not by ear.
- The script turns `…` and `...` into pauses; captions strip both.
